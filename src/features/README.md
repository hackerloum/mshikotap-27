# Features

Place feature-scoped UI and logic here as modules grow:

- `auth/` — forms, phone OTP UI, session bridges
- `tasks/` — task cards, proof upload, anti-fraud widgets
- `wallet/` — withdraw flows, fee calculators
- `referrals/` — invite share, multi-level trees
- `marketplace/` — listing composer, orders
- `challenges/` — race widgets, countdowns
- `campaigns/` — advertiser builders
- `notifications/` — inbox, preference center
- `gamification/` — XP, badges, streaks
- `analytics/` — role-specific insight panels

Keep domain mutations in `src/services` and shared primitives in `src/components`.
